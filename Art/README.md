# Editable art sources

One asset owner per binary source. Preserve `.blend`, export, dependent textures,
units, intended dimensions, orientation, hardpoint names, and origin/license.
Engine-ready copies belong under `Game/Daedalus/Content/`; source models here.

The foundation cruiser is original synthetic geometry: +X forward, +Z up,
Blender metres, engine centimetres, overall X length 120 m. It demonstrates
the reproducible source/export/import pipeline, not final art.
